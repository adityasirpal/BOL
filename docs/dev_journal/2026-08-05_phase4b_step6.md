## UploadService Refactoring

UploadService now owns:

- Incoming upload handling
- File metadata creation
- Physical chunk metadata creation
- Primary storage metadata helper

Transaction ownership remains inside FileService.

---

## Primary Storage Service

Created a dedicated Primary Storage Service responsible for creating canonical primary storage records.

The service now validates:

- duplicate primary prevention
- exactly one active primary per chunk
- transaction ownership by caller

This becomes the foundation for future automatic failover and re-replication.

---

## Architecture Direction

Responsibilities continue moving toward dedicated services.

Current direction:

FileService

↓

UploadService

↓

PrimaryStorageService

↓

ReplicaService

↓

RecoveryService

Each service owns one responsibility.
